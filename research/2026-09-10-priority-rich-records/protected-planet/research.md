## Identity and the backlog correction

Fresh canonical searches for Protected Planet, WDPA, WDPCA and WD-OECM returned zero results. Fresh individual reads of the main ID and every proposed dependency returned 404; there are therefore no existing incident edges or stored content to preserve. Evidence is in `canonical-search.json` and `canonical-prevalidation.json`.

The record is **Protected Planet, the platform**, with its principal protected/conserved-area inventory in scope. The [operator's current announcement](https://www.protectedplanet.net/news-and-stories/launch-of-new-wdpca-user-manual) confirms that WDPA and WD-OECM merged into the **World Database on Protected and Conserved Areas (WDPCA)** in November 2025. The [API notice](https://api.protectedplanet.net/) specifies 1 November 2025. Their older names are useful discovery aliases, not claims that separate unchanged databases still operate. GD-PAME and other thematic resources belong to the wider platform and are excluded from the inventory measurements.

The current [API v4 migration guide](https://api.protectedplanet.net/documentation/whats_new_in_v4) introduces `site_id`, string `site_pid`, and `site_type` distinguishing `pa`/`oecm`; the GIS layer uses uppercase `PA`/`OECM` values. It also distinguishes site records from parcels and adds governance/ownership subtypes, inland-water and OECM-assessment information. API v3 removal was announced for 1 May 2026; no live v3 behavior was established. Website notices explicitly acknowledge that some pages are still being updated. The old 29/31-attribute claim is not a current schema count.

## Access and actual checks

- Public map and site pages: documented and readable with the web research tool. No account prerequisite for browsing.
- Website downloads: the public site menu offers Shapefile, file geodatabase, CSV and PDF. Root opened the CSV option and verified the commercial-use route to IBAT and noncommercial Continue route. No Continue/terms acceptance or package download was performed. Account and fee mechanics were not verified in a completed session; requirements remain `null`, cost `unknown`.
- Main REST API v4: [documentation](https://api.protectedplanet.net/documentation) requires a token; the [request form](https://api.protectedplanet.net/request) states that approval precedes delivery of the key. The draft records `api_key` and `approval`, cost `unknown`. No authorized key was available or requested. Calls returned HTTP 403 to this client, rather than demonstrating the documented missing-token 401 response. Field restrictions can apply.
- **Verified independent machine read:** the public [UNEP-WCMC WDPCA FeatureServer](https://data-gis.unep-wcmc.org/server/rest/services/ProtectedPlanet/WDPCA/FeatureServer) advertises Query/Extract, point and polygon layers and a source table. A limited, geometry-free query returned the real Bonaire record without credentials: site 230, National Marine Park, designated 1979, STINAPA management, nonprofit governance, source metadata ID 1899. Evidence: `gis-service.json`, `gis-polygon-schema.json`, `gis-bonaire-check.json`. This verifies that bounded read, not arbitrary bulk extraction, an SLA or a write permission. It is a separate access row, not an invented approved Ryu route.
- Earth Engine: [Google's catalogue](https://developers.google.com/earth-engine/datasets/catalog/WCMC_WDPA_current_polygons) documents monthly point/polygon collections and archives from July 2017. An account and registered project are needed; [current noncommercial quotas](https://developers.google.com/earth-engine/guides/noncommercial_tiers) and other service charges apply. The catalogue's legacy names and fields do not establish full WDPCA parity. No authenticated asset query was executed.
- Commercial access: [IBAT services](https://www.ibat-alliance.org/services) provide licensed downloads and subscription/API options. [Protected Planet terms](https://www.protectedplanet.net/en/legal) define commercial use broadly, including use for or by a for-profit entity, not only resale. Commercial permission and redistribution permission are distinct. Google/IBAT access does not automatically permit republishing downloadable WDPCA data.
- Contributions: the [official guides](https://www.protectedplanet.net/en/resources/wdpa-manual) and data-justice account support curated submissions from governmental and non-state providers; data standards, verification and agreement apply. The terms welcome corrections and revised GIS data through the listed contacts. Neither path is a public write API. Submission fees were not established, so cost is unknown.

No data package was downloaded or redistributed, no token requested, no form submitted, and no public-service write attempted. API metadata capability flags are not authorization for editing.

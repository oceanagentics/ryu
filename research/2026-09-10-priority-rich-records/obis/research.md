## Identity, scope and evidence

The [OBIS homepage](https://obis.org/), [governance page](https://obis.org/about/governance/) and [manual](https://manual.obis.org/policy.html) establish the Ocean Biodiversity Information System, initiated under the Census of Marine Life in 2000 and adopted by IOC in 2009. Its central secretariat coordinates an international node network within IODE. Providers retain ownership; OBIS integrates and enriches published marine biodiversity data. Global coverage includes areas beyond national jurisdiction, but no independently verified support was found for the backlog's specific 2.7-million-ABNJ-events figure.

The record covers occurrence observations, taxonomy, survey records, associated environmental measurements and DNA-derived data. A live public API sample actually returned the DNA extension and sequence content (`api-dna.json`); another returned eMoF content (`api-emof.json`). These demonstrate supported content, not universal completeness. Coordinate-derived environmental enrichment must not be mistaken for simultaneous field measurements. Defaults and exports differ: some lookup paths exclude absence records, while the documented AWS dataset includes absence and dropped records. No presence-only claim is made.

## Access, formats and standards

The [current access page](https://obis.org/data/access/), [manual](https://manual.obis.org/access.html), [public API contract](https://api.obis.org/obis_v3.yml), [robis documentation](https://iobis.github.io/robis/) and [AWS repository](https://github.com/iobis/obis-open-data) support public mapper lookup/download, API JSON, R access, original dataset archives and bulk Parquet access. Small public API and S3 requests worked without credentials. The API explicitly discourages parallel downloads; bulk work should use the archive/snapshot paths. Public data access is free; optional external compute charges are a separate matter.

The current access table calls mapper downloads TSV, whereas older manual prose says CSV. TSV is the candidate's explicit format assignment; a downloaded mapper file's delimiter was not independently inspected. Root inspected the live mapper export dialog: browsing is account-free, but export requires an email address to enable confirmation. The dialog warns that email notifications are currently not operational and tells users to keep the window open for download status/link; optional eMoF and DNA extensions are available. No user email was submitted. This requirement and warning are included in all six access descriptions, with a mapper citation. The mixed browse/download path uses `requirements: null` rather than falsely claiming verified absence of prerequisites; no unapproved email requirement ID is invented. Original Darwin Core Archives include provider metadata and may omit OBIS-added quality-control/enrichment columns. AWS GeoParquet maps to the approved `parquet` format. DNA preparation examples do not justify asserting an independently available FASTA delivery interface.

Contribution is node-mediated, followed by data/metadata preparation and IPT publication. The [contribution guidance](https://obis.org/data/contribute/) and [IPT manual](https://manual.obis.org/ipt) support a request path and an account-based form/upload/harvest path. Node managers provide IPT accounts; unspecified onboarding requirements and contribution charges remain unknown rather than assumed free. Accepted dataset licences include CC0, CC BY and CC BY-NC, so unrestricted reuse is not universal.

Scoped standard assignments are Darwin Core, EML, eMoF, DNA-derived-data extension and NERC vocabularies. [Vocabulary guidance](https://manual.obis.org/vocabulary.html) recommends P01/P06 and permits other suitable URI vocabularies; it does not certify every record. No MIxS checklist conformance, planned Humboldt implementation, or WoRMS-as-a-standard is invented. All assignments have owner-local citations and descriptions in six locales. Machine interfaces are described in access; `routes` remains empty because this research does not approve an operational Ryu route.
